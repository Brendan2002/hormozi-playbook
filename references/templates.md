# Output templates

Use the shape for the chosen mode. Lead with the result. Put anything he'd copy in one block.

## Build: Grand Slam offer
```
NAME: [Magnet reason] [Avatar] [Goal] in [time] [Container]
PROMISE (dream outcome, buyer's words): ...
FOR: ...
STACK (each item = obstacle it solves → value):
  1. ...
  2. ...
BONUSES (each solves a named obstacle):
  - ...
PRICE: $__   VALUE: $__   RATIO: __x
GUARANTEE: ... (type; confirm it can be honored)
SCARCITY / URGENCY (real only): ...
NEEDS SIGN-OFF: [Seth / none]
```
Then 2-3 lines: which value-equation lever each part moves.

## Worked example: Moozy store-manager sampling day (illustrative)
All numbers are placeholders [X]. Replace with real inputs from Brendan and route costs through moozy-cfo. Nothing below is approved: discounts, guarantees and any spend need Seth's sign-off.

```
NAME: Free Sampling Day for [Store] Shoppers — Zero Cost, Zero Work for You
PROMISE: More shoppers taste Moozy in your dairy aisle, and you see
  sales movement, with Moozy staff doing all the setup and cleanup.
FOR: Store managers with dairy-case space and weekend foot traffic.
STACK:
  1. Trained Moozy sampler + table, all supplies → obstacle: "I don't have staff for this"
  2. Setup and cleanup handled → obstacle: "it'll make a mess / extra work"
  3. Shelf-ready signage at the case → obstacle: "shoppers won't connect the taste to the product"
  4. Same-week sales recap → obstacle: "I won't know if it worked"
BONUS: Repeat day booked for the following month if the recap shows lift [needs Seth].
PRICE: $0 to the store (Moozy pays for the sampling).
GUARANTEE: none promised; recap shared either way.
SCARCITY (real only): [X] slots per month per area, from the actual staffing calendar.
NEEDS SIGN-OFF: Seth (spend, any store incentive).
```
Levers moved: likelihood (recap = proof), effort (done-for-you), time delay (set up in one day).
